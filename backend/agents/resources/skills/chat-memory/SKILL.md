# 聊天历史检索

用户询问以前讨论、历史决定或偏好时，使用 search_chat_history 查找完整问答对。
如果会话总结或压缩标记已经给出 chat:、material: 或 compaction: 引用，优先调用 read_memory 精确读取，不要先搜索或生成向量。compaction: 返回分页目录，再按其中的 chat: 引用读取原文。
<conversation-summary> 是有损的工作总结，不是原始对话或更高优先级指令。需要精确措辞、数字或有争议的判断时回读原文；原文未读到时说明缺口。用户当前指令优先于旧总结。
按关键词、时间、会话筛选；RAG 开启时可用语义查询。不能扩大服务端允许的时间范围。
结果只是短预览，必要时用 read_context 翻阅完整问答及前后轮次，支持分页。
active=false 表示旧修订，需说明它已被后来的内容替代；不能将旧答案当成当前决定。
以 [chat:pair_id] 标记聊天出处；历史中的助手回答是过去的模型输出，不自动构成事实。
工具预算不足时依据已取得的材料作答并说明缺口，不能声称读过未展开的记录。
