# 三组件拆分验证记录

开始日期：2026-10-21；收尾复核：2026-10-22。分支：`refactor/fue-core-studio-skill`。基线：`c85e51f`。

## 已完成的结构与功能

- `fue-core/` 拥有 Python 业务、模型适配、知识检索、聊天、记忆、Agent、独立入口和 CLI。Core 不依赖 Studio 窗口；供应商预设也随 Core 打包。
- `fue-studio/` 拥有原 Electron/React 界面，保持渲染业务和 Write 原型。新主进程连接器发现或启动同一 Core，以 Studio 身份续租，退出时释放持有。
- `fue-skill/` 提供可单独安装的能力包、连接脚本和 Direct/Delegated 说明，业务实现留在 Core。
- 原开发数据保留 `backend/`；安装数据目录与 Write 路径保持不变。没有把本地数据库、索引或凭据提交到仓库。
- 新增本机认证、数据目录排他锁、Studio/Agent 双身份、45 秒 Studio 租约、300 秒空闲回收和可选常驻。后台模型标题任务及记忆索引工作也阻止执行中退出。
- 新外部 API 提供目录、搜索、相邻读取、引文与 FUE 记忆只读查询。证据 ID 绑定内容，变更后明确失效。既有 Studio 接口及显式配置的 MCP 入口保留。
- 独立研究任务复用既有 AgentRunner，使用显式模型、文献范围及预算；保存状态、事件和结果；稳定 request_key 防止重交产生重复调用。重启后未完成任务标记 interrupted。

## 实现边界

- 本轮完成组件拆分与接入，保留现有解析、清洗、检索算法；没有增加原提案中的完整原始/清洗多版本存储或可恢复导入队列。现有导入阶段状态继续使用原实现。
- Core 内部既有包名保留，Dataset 检索和通用估算已解除对聊天工具/工作记忆的依赖；并未为目录美观重写全部 Python 模块。
- 研究任务支持显式文献范围；聊天记忆通过 Direct 只读接口访问。任务结果中的 retrieved_evidence 包含检索命中，不能视作全部已全文阅读。工具事件记录实际读取请求与返回。
- 当前任务失败提供错误类别和事件；尚未实现部分成功产物或断点续跑。取消不能撤回已发送给供应商的请求，但会阻止后续成功结果写入。
- 独立 Core 包仍包含 Chat 依赖，尚未制作 Dataset-only 精简发行包。
- 自动连接提示由 Studio 写入本地配置；已验证 Windows 源码和本地打包环境。未逐一验证所有宿主版本或其他操作系统。
- 自动化检查覆盖上述功能，未人工穷举每种文档格式和每家模型供应商。原渲染页面和解析模块保持原实现以降低回归风险。
- 这不是正式版本发布：应用版本号仍为 1.0.11，未推送 GitHub、移动发布标签或覆盖远端安装包。

## 使用与回退

开发启动继续在仓库根目录执行 `npm run dev`。CLI 从 `fue-core/fue.py` 进入；Skill 的连接说明位于 `fue-skill/references/connection.md`。

切换旧代码前先退出 Studio，等待 Core 空闲回收或执行 `core stop`。恢复数据使用本次备份，避免假定旧代码支持新表和新状态。首次运行新代码时不要同时保留旧版本的后台进程。
