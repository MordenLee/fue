## 使用与回退

开发时仍运行 `npm run dev`；本机 `.fue-workspace.json` 已选择迁移后的资料目录。启动时按需备份并升级 SQLite schema。旧 `backend` 保留为复制时点的回退副本，后续新对话不会双写回旧目录。

需要回退资料目录时先关闭 Core，再明确选择旧资料库；需要回退 schema 时按架构文档恢复相应数据库快照并使用兼容版本。不要在两个副本之间交替写入并期待自动合并。
