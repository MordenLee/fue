## 验证边界

所有集成验证使用项目内隔离注册表、测试资料库和测试宿主目录，没有修改真实宿主配置，也没有调用收费模型。

本轮实际运行环境为 Windows。源码安装时在线 pip 下载依赖的分支没有做联网安装验证；macOS/Linux 未做端到端验证。桌面卸载脚本提供是否保留共享 Core 的明确选择，资料库单独保留；未对用户机器执行真实卸载。备份目前针对 SQLite，不声明支持 Chroma 格式迁移。

后续卸载选择调整：安装模块扩展到 13 项测试并通过，全量 78 项测试通过。新增验证安装器管理的 Core 可删除、用户自管环境和资料库保留、Core 活跃时拒绝删除、所有权标记缺失或与资料库重叠时拒绝删除。

包含交互式 Core 保留/删除提示的 Windows NSIS 安装器及卸载器编译通过（本地 `dist-uninstall-check` 测试包）；同时排除了 `dist-*` 旧测试产物，避免重复打包。未执行用户环境的安装或卸载。

离线 Agent 包可以本地生成；GitHub 资产上传和正式安装器发布属于后续发布操作。
