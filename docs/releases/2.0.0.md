# FUE 2.0.0

更新日期：2026-10-22。

本次升级将 FUE 拆分为 Core、Studio 和 Skill 三个组件，并增加携带向量的知识库 JSON 迁移。保留聊天、知识库、模型配置和记忆管理能力；写作入口暂时隐藏，留待后续版本继续开发。

## 架构重构

- **FUE Core**：独立管理数据、检索、聊天记忆、模型调用和研究执行，提供本地 API 与 CLI。
- **FUE Studio**：负责桌面界面，启动时发现并连接 Core；同一个数据目录只运行一个 Core。
- **FUE Skill**：提供外部 Agent 的接入说明和脚本，支持查询、阅读上下文、引用与研究委托。
- Studio 与外部 Agent 使用不同身份。宿主可读取 FUE 资料，但不把宿主聊天或记忆反向同步到 FUE。
- Core 跟随 Studio 按需启动；无 Studio、无正在执行的工作且空闲约五分钟后自动退出，也可配置常驻。
- 研究任务持久记录状态、事件和用量，支持幂等提交与取消；来源知识库删除后仍可取消已有任务。

## 知识库 JSON 导入导出

- 导出文档分块、已有向量、摘要、引用和知识库设置；导入直接恢复，不调用清洗、提取或嵌入模型。
- 知识库列表新增“导入 JSON”，可预览源模型、维度、文档数和分块数，选择本地嵌入模型及新名称。
- 导入创建新知识库，同名文档独立保留，恢复关键词检索、向量检索、引用与前后 chunk 阅读。
- 校验模型配置、文件完整性、文档关联、chunk 序号及向量数值；不兼容时拒绝导入。
- 新索引记录嵌入配置；旧索引缺少来源记录时要求明确确认，且保留未验证标记。
- 写入异常时回滚 SQLite 并清理新 collection；禁止对缺少原始附件的导入文档直接重新索引，以保护已有向量。

迁移不包含原始 PDF、图片等附件，不携带提供商密钥或本地文件路径。单个 JSON 上限为 256 MiB，要求所有文档完成索引。格式版本为 2.0；旧文件需从原知识库重新导出。模型同名不保证远端模型权重未发生变化，离线迁移不进行付费探测。

## 界面与启动修复

- 修复 Windows 下启动 Studio 时额外弹出 Python 黑色终端的问题；Core 改用无窗口解释器，CLI 保留正常标准输出。
- 隐藏写作导航与页面路由，原有写作数据和实现保留；旧写作地址返回聊天页。
- 补充中英文导入提示、进行中状态与错误反馈。

## 升级与开发

源码目录调整为 `fue-core/`、`fue-studio/`、`fue-skill/`。开发数据继续使用原 `backend/` 目录，已安装应用继续使用原用户数据目录；不要删除或移动数据目录作为升级步骤。

更新依赖后，在仓库根目录运行 `npm run dev`。已运行的 Core 必须退出后再启动才能加载新的 Python 接口，单独刷新界面不够。关闭 Studio 后，Core 在没有活动任务且空闲约五分钟时自动退出。

工作记忆继续保持可选，默认关闭；开启方法及压缩费用说明延续 1.0.11。知识库迁移本身不产生模型费用，但后续语义查询、研究和回答仍可能调用已配置的模型。

本次同步源码与版本标签。GitHub 上的历史 1.0.11 安装包不代表 2.0.0；本说明不宣称旧安装包已更新。

## 验证与限制

- 65 项 Python 回归测试通过，其中包含 7 项知识库迁移测试；使用真实 Chroma 与隔离 SQLite，验证完整往返、检索、引用、上下文、错误拒绝和部分写入后的回滚。
- Studio 类型检查与生产构建通过；实际 Electron 导入弹窗已检查。
- Windows 后台 Core 无控制台启动、Studio 退出后 Core 继续存活已验证。
- 本轮验证未调用付费模型，未修改用户现有知识库。
- SQLite 与 Chroma 不支持跨库原子事务；强制终止进程可能留下没有数据库记录引用的孤立 collection。
- 暂不提供超大 JSON 流式导入、原始附件打包、跨模型向量转换或写作新功能。
