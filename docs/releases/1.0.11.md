# FUE 1.0.11

2026-10-21 同版本更新，核心优化：增加长对话记忆管理。版本号保持 1.0.11，请重新下载安装包获取本次更新。

## 本次记忆管理优化

- 增加可选的“工作记忆”模式：按输入/输出预算组织长对话，必要时生成限长 summary.md，并保留完整原始问答。
- 材料可明确标记为已处理，填写保留结果后从后续上下文移出全文；支持恢复全文。
- 保存压缩记录及来源，Agent 可用 read_memory 按问答、材料或压缩记录 ID 精确回读，不必先进行向量搜索。
- 展示模型/工具执行、总结压缩、材料清理和近期用量；流式等待期间保持状态可见。
- 增加每轮 token 账本与预算，复用相同查询的向量；修复兼容提供商逐块返回累计用量时重复相加的问题。
- 总结更新校验来源版本；编辑、删除同步处理派生记忆，生成文件不进入源码或安装包。

新模式默认关闭。启用路径：设置 → 对话设置 → 长对话上下文模式 → 工作记忆；需明确选择压缩模型，并允许历史回读。不会自动总结旧会话。

## 更新

- 修复设置下拉菜单中勾选图标与选项文字重叠；为图标预留独立空间，菜单宽度至少与输入框一致。
- 将 Chat Agent 的指令、Skill 声明与工具执行逻辑解耦，并接入实际 Python 对话流程。
- 增加聊天历史问答对索引、变更日志、关键词与语义检索，以及按时间范围控制历史访问。
- 聊天和知识库分别支持关键词模式与关键词加语义模式；支持读取历史问答和文档片段的相邻上下文。
- 对检索预览、阅读内容和工具调用设置预算；修复重复检索与工具执行结果衔接问题。
- 修复编辑、重新生成及删除对话时的历史与索引同步，并提供索引状态和重试入口。
- 安装包版本更新为 1.0.11，打包脚本按应用版本生成文件名；安装包不包含开发数据库、知识库向量数据或提供商密钥。

## 当前限制

- token 预算采用估算与提供商返回用量，不是精确金额封顶；后台索引尚未归入具体聊天轮次，没有货币价格表或完整运行恢复。
- 摘要是有损的模型输出，可能对材料状态过度推断；精确判断需回读原文。已增加说话人标注，但不能保证摘要完全准确。
- 超大单条材料、禁止历史回读、来源超出时间范围或未配置压缩模型等情况会明确停止，不静默丢弃内容。自动多级摘要和多次压缩的全面质量评估仍待后续工作。
- 写作功能为现有原型，多人协作尚未实现。
